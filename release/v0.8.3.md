# Sonic the Hedgehog 2 Recomp v0.8.3

Coverage update for the shared Japan/USA/Europe REV01 / World Rev A ROM
(CRC32 `7B905383`), running at NTSC timing. Supply your own matching ROM.

Two source-verified single-entry tables now compile natively: the Wing
Fortress cloud handler and the Metropolis Slicer pincer orientation handler.
The conservative general table extractor still requires multiple entries.
Native coverage gains nine instruction starts with no losses.

The shared engine includes the PLC full-bus-address fix, improved Sonic 1
disassembly tooling, and the mixed-width guest-stack return correction.
Strict stack checks remain enabled during QA; runtime compatibility checks
remain unchanged.

Validation covers 20 original act starts and all seven special-stage entries
in both stock and 32:9 modes. All 40 final act-start routes report no dispatch,
interior-label, floor or unsafe-floor misses. Four affected Metropolis/Wing
Fortress runs match interpreter-floor references exactly in entry/final RAM,
VRAM and screenshots. Final shared-core replays retain all 40 route results.

This bounded assisted pass does not certify every boss victory, the ending,
every alternate path, or cross-build netplay. Widescreen remains experimental
under Mods. Keep settings and cartridge saves; quick states require the same
build and configuration.
